# Tunay Wasi — Estrategia de Contenido Orgánico
### TikTok · Instagram · Facebook — Fundador como voz

> **Objetivo fase 1 (semanas 1–4):** Construir comunidad que entiende el problema.
> **Objetivo fase 2 (semanas 5–8):** Mostrar la solución. Invitar al registro.
> **Métrica norte:** Seguidores + guardados de carruseles (señal de que el contenido educa).

---

## LÓGICA DE CONTENIDO

```
SEMANA 1–2: EL PROBLEMA (indignación)
"No sabías esto del café peruano"
→ Datos que sorprenden. El seguidor siente que aprendió algo.

SEMANA 3–4: LA CAUSA RAÍZ (educación)
"Por qué pasa esto y quién gana con el problema"
→ El seguidor entiende la cadena. Empieza a seguirte como experto.

SEMANA 5–6: LA HISTORIA (conexión)
"Conoce a Darlyn, produce Geisha en Oxapampa"
→ El caficultor tiene cara y nombre. El seguidor ya no puede ignorarlo.

SEMANA 7–8: LA SOLUCIÓN (conversión)
"Lo que estamos construyendo para cambiar esto"
→ El seguidor ya entiende el problema. Ahora escucha la solución.
```

## GUÍA DE USO

### Frecuencia recomendada
```
Instagram:  3–4 posts/semana (carrusel + stories de detrás de cámara)
TikTok:     2–3 videos/semana (guiones arriba + adaptar en 60s)
Facebook:   2 posts/semana (posts de texto largo + carruseles)
```

### Hashtags base (rotar, no usar todos siempre)
```
Educativos:  #cafedeespecialidad #specialtycoffee #caficultor
             #origenperu #cafeperu #calidadcafe #qgrader
Comunidad:   #cafeteriaperu #tostadora #baristaperu
             #cafelima #cafeteriaslima
Reach:       #peru #emprendimiento #agronegocio
             #sostenibilidad #comerciojusto
```

### Qué funciona más en cada plataforma
```
TikTok:      Hook en los primeros 3 segundos.
             El dato sorpresivo primero, la explicación después.
             Texto en pantalla siempre (muchos ven sin audio).

Instagram:   Carruseles con primera slide como gancho visual.
             Stories para mostrar el proceso real (finca, catación).
             Guarda el link en bio para el registro.

Facebook:    Texto largo funciona bien (la audiencia es mayor, lee más).
             Grupos de cafetería/hostelería para distribución orgánica.
```

### Llamada a la acción por fase
```
Semana 1–4 (problema):    "Sígueme para la próxima parte"
                           "Comparte si crees que esto debe cambiar"

Semana 5–8 (solución):    "¿Eres tostadora o cafetería? Escríbenos"
                           "Regístrate en la lista de espera"
                           "Link en bio → marketplace.tunay-wasi.com"
```
